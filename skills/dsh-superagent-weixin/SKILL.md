# 微信（iLink Bot）渠道约束

这是个人微信里的官方机器人（腾讯 OpenClaw Weixin / iLink 协议，客户端需微信 ≥ 8.0.69）。回复会直接出现在对方的微信私聊里，按手机阅读来写。

## 能做什么

- 收：私聊里的文本；语音消息带手机转写时按文本处理；图片、文件、视频只作为消息存在，本渠道不下载媒体内容。
- 发：文本回复，超长按约 4000 字符分块发送，每块独立幂等。
- 查：对方 wxid（触发里带）、消息 id、消息时间。

## 不能做什么

- 读不到历史：iLink 没有历史消息接口，触发只带这一条消息本身。不要假设你「记得」之前的对话，除非它在本会话上下文里。
- 不支持群聊：带 `group_id` 的消息在当前实现里直接丢弃。
- 不主动发起会话：只能在对方最近一条消息之后 **24 小时**内推送。超时后发送会失败，必须等对方再发一条。

## 回复纪律

1. 先说结论，一段话说清；手机上看不完长段落。
2. 不要用大段代码块、表格或嵌套列表；需要细节时给一句摘要并说明在桌面端可以看完整记录。
3. 需要对方做决定时，把选项压到 2–3 个，用「回 1 / 回 2」这类最短路径。
4. 不要重复发送相同内容：同一条回复重试是幂等的，但内容变了就是新消息。
5. 24 小时窗口临近或已过期时，直接说明「需要你先发一条」而不是静默失败。

## 故障信号

- 发送报 `-14`：bot token 失效，需要重新扫码登录（重启插件后会重新出二维码）。
- 发送失败但非 `-14`：可能是 24 小时窗口已过；提示对方再发一条消息。
- 长轮询 35–40 秒断一次再连是正常的，不代表掉线。

## 使用技巧

- 想让任务持续跟进，就在微信里说「继续」或「现在到哪了」，这是最便宜的重启信号。
- 需要长任务时，先发一条简短指令（例如「推进高斯试点」），等我回执后再离开；结果会在窗口内回推。
